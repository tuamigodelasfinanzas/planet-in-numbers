# Planet in Numbers (@theplanetinnumbers)

Fully automated reels and carousels with real World Bank data, in the brand colors.

**How it works:** Make launches `.github/workflows/publish.yml` three times a day with the slot
(A 06:00, B 11:00, C 18:00, Madrid time). `content/plan.json` says which series goes out in each slot.
The workflow builds the content with real data, renders it, uploads it to GitHub Pages and calls
the Make webhook, which publishes on Instagram and Facebook. Reels also go to Telegram (for TikTok).

| Series | Format | What it is |
|---|---|---|
| top10 | reel | Countdown Top 10 of a topic |
| dollar100 | reel | How far $100 goes (price levels) |
| race | reel | Bar chart race, then vs now |
| map | reel | World map colored by a topic |
| stat | reel | The biggest gap between two countries |
| guess | reel | Quiz: guess the country from 4 clues |
| top20 | carousel | Full Top 20 (7 slides) |
| versus | carousel | Country vs country, 5 rounds |
| week | carousel | The week in numbers |

Topics: `content/topics.json` (World Bank indicators). Pairs, quiz countries and regions: `content/catalog.json`.

Secrets: `MAKE_WEBHOOK_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, and for stories `IG_ACCESS_TOKEN` + `IG_USER_ID`.

Local test without internet: `node tools/make-fixture.mjs fix && PIN_FIXTURE=fix node src/build.mjs top10 item.json && PIN_VOZ=false node src/render-reel.mjs item.json out/reel.mp4`
(fixture numbers are fake, only for layouts).

Data: World Bank Open Data (CC BY 4.0). Map: world.geo.json (public domain). Music: generated by `tools/make_music.py` (original, royalty-free).
